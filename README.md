# VEP：从一段提示词到纪律化持仓管理系统

> **项目性质：个人兴趣研究 / AI 辅助开发 / 持续完善中。** GitHub 公开审稿稿 v0.5 · 2026-10-11。核心交易策略、内部参数与真实账户数据不公开。

这是出于个人投资兴趣不断改进的非商业研究项目，不是成熟的投资产品。我具备一些计算机理论和程序逻辑思维，能分析 Agent 的运行过程、判断结果是否符合设计要求，但缺少独立编写软件的实践能力。公开它是为了记录我如何与 AI 一起讨论方案、亲自实操、调试验证，再逐渐让 Agent 承担更多工作；欢迎建设性的技术讨论。系统仍有未解决的问题，不能保证投资收益或始终正确执行全部规则。

## 为什么做 VEP

最初，我只是想做一个帮助自己的股票分析工具。我了解一些计算机原理与类似 C++ 的程序逻辑，但没有独立写软件的能力，于是从一段提示词开始，让 AI 按自己的思路研究行情和整理持仓。

我的主要目标不是预测每一次涨跌，而是建立一套**尽可能理性、以仓位管理和交易纪律为中心的决策方法**：控制自己的资金和风险，不因一次盈亏或临时情绪随意改动计划。我把这种对自己账户的控制称为“控盘”，与操纵市场或股价无关。

真正使用以后，问题接连出现：模型换个对话就忘掉过去的判断；旧账户信息被误当作最新状态；有时报告写得完整，资料却没核实。于是我不断追加复盘记录、约束、分类和数据校验，VEP 也从提示词逐渐发展为有持久记录、独立程序和数据来源管理的系统。

这套体系不是先设计好再一次性写出来的。**它的变化，几乎每一步都来自实际使用中暴露的问题。**

## VEP 理论的公开部分

它首先是一套**持仓与风险管理体系**，AI 是辅助分析和执行纪律的工具，而不是替代纪律的理由。

- 先判断市场与中长期方向，再考虑具体买卖时点；短期波动不能随意推翻更长期的判断。
- 先考虑整个账户的风险和仓位配置，再考虑某一只股票。
- 区分不同仓位的任务，避免无理由卖强留弱或把问题仓当成长期核心。
- 重要调整需要明确的事实、条件与风险依据，而不是追逐一时的涨跌。
- 保留过去的判断，但要用最新可核实的信息修正它，不能把旧资料当成今天的事实。

完整评分、交易触发条件与内部策略属于私有部分，不在公开稿中提供。

## 一路怎样做出来的

**提示词 → 历史交易档案 → 桌面自动化与截图分析 → 结构化数据与工具脚本 → 长期状态和规则管理。**

早期 Agent 不容易直接使用电脑，我尝试给它配上启动股票软件、截图、视觉分析及操作脚本，作为它的“眼睛”和“手”。后来随着工具发展，我开始研究让 AI 使用经过授权的数据接口与指标代码，建立自身可调用的工具，不必每次都通过屏幕截图获取信息。

现有项目已有程序文件、证据输入包和相关运行规则，但各阶段的完整可靠性尚需继续核对。详见 [开发沿革](docs/history.md)。

## 历史测试的真实情况

我曾用自己的历史交易记录进行复盘，个人当时估计判断符合预期的比例大约在 **60%–70%**，感觉比自己临场凭情绪操作更有秩序。但尚未整理出能独立复现的样本、统计定义和基准，**这不是已验证的策略胜率，更不是收益保证**。

## 现在最棘手的问题：还没有解决

虽然我不断把规则写入长期存储和执行文件，**AI 至今仍不能保证每次完整读取、理解和执行全部适用规则**。它有时会漏掉要求、简化步骤，或者做出与既有约束不一致的判断。

**我目前采用的办法之一，是 VEP 的 21 项输出合同。** 每次输出正式分析时，必须按固定栏目逐项填写；发现缺少栏目，就先返回补齐，再交付报告。这有助于减少最终报告的内容遗漏，但不代表内部分析过程一定完整，更无法证明所有策略纪律都已经遵守。这个问题仍未彻底解决。

**下一步，我准备研究多 AI 协同工作。** 我的设想是让不同 AI 分工完成分析，再安排一个专门的**审核 AI**，独立对照 VEP 规则检查其他 AI 是否按纪律完成任务、哪里出现遗漏或冲突，再交由我确认。**这目前只是研究方向，没有实现，更不能保证审核 AI 自身永不出错。**

具体状态见 [尚未解决的问题与下一步想法](docs/rule-adherence-gap.md)。

## 关于开发方式

我不仅提出需求，也会从计算机逻辑和业务规则的角度分析 Agent 哪里可能跑错，检查输出与流程。早期我不断与 AI 讨论可行方案，再根据它给出的步骤亲自在电脑上配置、操作、测试和排错；后来才逐步让 Agent 自动完成一部分技术工作。大量代码和文档由 AI 辅助编写，但实际使用中的设计取舍、问题发现、验证和改进方向一直由我参与决定。我不把自己描述为独立编写完整系统的程序员，也不会把尚未完成的工作说成已实现。

本项目用于分享 AI 辅助开发实践，不构成投资建议，也不提供自动交易或盈利保证。
